# spotify-api-top

Using spotify API to create TOP20 song playlis out of massive original playlist

## How to use

To use the console application just add user secrects for SpotifySettings POCO. Remember to add http://127.0.0.1:6001/callback to callback server in the spotify API console.

## Example

When run the console app requires the 6001 port to be open. Then it asks the user to login with their spotify account.
Then user selects the source and target playlist and can choose to abort if the songs are not to their liking
